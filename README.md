# Sentinel V1.0.0 – Initial Release

Sentinel is an ASP.NET Core MVC web application for tracking and managing software errors, bugs, and security-related events.

### Features
- Organization management
- Project management and archiving
- Service management
- Error and security event tracking
- Event severity and status management
- Audit logs
- Dashboard analytics and event trends
- Dark cybersecurity-inspired interface

### Technology Stack
- ASP.NET Core MVC (.NET 10)
- C#
- Entity Framework Core
- SQLite
- Bootstrap
- HTML, CSS

### Version 1.0 Scope
This release provides a foundation for manually recording, organizing, and monitoring software errors and security-related events.

**Note:** Sentinel is a tracking and management application. It does not currently perform automatic vulnerability scanning or threat detection.

### Future Development
Future versions may introduce authentication, automated event ingestion, advanced analytics, and deployment enhancements.
